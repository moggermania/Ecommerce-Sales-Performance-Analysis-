# E-Commerce Sales Performance Analysis using Data Analytics and AI

**Student:** Paras

## Project Overview
This project performs end-to-end e-commerce sales analysis using Python, data analytics, visualization, statistics, and machine learning.

## Objectives
- Clean and prepare e-commerce order data.
- Analyze sales by category, region and channel.
- Study monthly sales trends.
- Explore discount, quantity, ratings and sales relationships.
- Train Linear Regression and Random Forest models.
- Evaluate models using MAE, RMSE and R².
- Identify important predictive features.
- Generate AI/ML-based analytical insights.

## Dataset Note
The included dataset is **synthetic**, created specifically for this educational project. It is not official company or market data.

## Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Joblib and Jupyter Notebook.

## How to Run
1. Install Python 3.10+.
2. Run `pip install -r requirements.txt`.
3. Open Jupyter Notebook.
4. Open `notebook/Paras_EcommerceSalesAnalysis.ipynb`.
5. Run the cells from top to bottom.

## Machine Learning
Target: `Sales_INR`

Models:
- Linear Regression
- Random Forest Regressor

The dataset uses an 80/20 train-test split.

## Key Generated Results
